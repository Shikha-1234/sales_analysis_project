# Sales Analysis Project

## Overview

This project analyzes the Sample Superstore dataset using Python and Pandas.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Business Questions Answered

1. Which category generated the most sales?
2. Which category generated the highest profit?
3. Which month generated the highest revenue?
4. Which products generated the highest sales?
5. Which states generated the highest sales?
6. Which category was the most profitable?
7. Which sub-categories generated the highest sales?
8. Which states generated losses?
9. Which region generated the highest sales?
10. Which region generated the highest profit?

## Visualizations

- Sales by Category
- Profit by Category
- Monthly Sales Trend
- Top 10 Products by Sales
- Sales by Region
